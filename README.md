# LEVEL3: Machine Learning and MLOps Engineering

This folder contains the production project materials from the LEVEL3 workshop at Arkadia Heilbronn. The course is structured by AppliedAI. It focuses on hands-on machine learning work, starting with a week-1 regression task built on the Titanic dataset.

## Overview

The goal of this repository is to provide a structured, reproducible place for the course artifacts. It includes the dataset, a project handout, and a notebook template to implement and document your solution.

## Repository layout

```
prod_project/
	README.md
	week-1/
		data/
			titanic.csv
		project_handout/
			README.md
		templates/
			LICENSE
			titanic_survival_part_2_template.ipynb
```

## Getting started

1. Review the instructions in the handout: see the README in the project_handout folder.
2. Open the notebook template in templates and work through the tasks.
3. Use the dataset from week-1/data as the input for your experiments.

## Week 1: Regression models

The first week focuses on building a binary classification model on the Titanic dataset. The notebook template guides you through data loading, preprocessing, model training, and evaluation.

## Data

The primary dataset lives at week-1/data/titanic.csv. Keep a copy of the original file intact and store any derived data in a separate location to preserve reproducibility.

## Notes

- This folder does not include a pinned requirements file. Install the packages referenced by the notebook in your preferred environment.
- The notebook template is a starting point; feel free to extend it with your own experiments and commentary.
